What Are Agent Skills?

  • Specialized instruction sets that enhance AI coding assistants
  • Each skill is a folder with a SKILL.md plus optional scripts and resources
  • Loaded dynamically by the agent only when relevant to the task
  • Standard spec at agentskills.io, supported by Claude Code, Cursor, Cortex Code, Codex, Gemini, Copilot
LayerRole
SKILL.mdInstructions and best practices the LLM follows
scripts/Helpers the agent can run
templates/Starting code the agent can copy

The Problem They Solve

  • LLMs default to outdated or generic Streamlit patterns
  • They miss caching, fragments, session state, and theme APIs
  • Code review burden falls on the user, every single time
  • Generic prompts cannot capture Streamlit specific best practices

Anatomy of a SKILL.md

  • Each skill is a self-contained Markdown contract
  • YAML frontmatter tells the agent when to load it
  • Body contains rules, code patterns, and footguns to avoid
SKILL.md 

---
name: optimizing-streamlit-performance
description: Caching, fragments, forms, and widget rerun patterns
---

# When to use
Apply when the app re-runs unnecessarily or feels slow.

# Rules
- Cache pure data with `st.cache_data`
- Cache resources (DB connections, models) with `st.cache_resource`
- Use `@st.fragment` to scope reruns to a section
- Wrap multi-input flows in `st.form` to batch reruns

# Footguns
- Do not cache mutable objects without TTL
- Avoid recreating connections on every rerun

How an Agent Uses Skills

  • Loads the matching SKILL.md into context
  • Generates code that follows the skill's rules

Agentic Workflow

  • Skills turn a one-shot prompt into a guided build
  • You stay in plain language, the agent stays on the rails
StepWhat happens
1. IntentYou describe the app you want
2. RoutingParent skill selects relevant sub-skills
3. GenerationAgent applies best practices from each skill
4. IterationYou refine, agent re-loads matching skills

Why This Matters

  • Quality is encoded once, reused by every developer and every agent
  • Streamlit team ships the source of truth for "good Streamlit code"
  • Skills are versioned, reviewable, and contributed back via PRs
  • Works across IDEs, no lock-in to one assistant
